# 🧭 TripGenie AI — Intelligent Personalized Travel Companion

TripGenie: AI-Powered Travel Companion
 Project Leads / Developers: Rugved Thorat (Roll No. A51) & Rehan Solanki (Roll No. A49)
 Tech Stack: React Native (Expo), TypeScript, Node.js, Express, MongoDB Atlas, Google Gemini AI
1. What is TripGenie?
TripGenie is a mobile and web application designed to help users plan trips easily using Artificial Intelligence. It features smart budgeting, automated itinerary planning, an AI chatbot, and a built-in catalog of over 50 destinations across India.
2. Key Features
 AI Trip Architect: Automatically generates day-by-day travel itineraries based on user preferences.
 Smart Budget Planner: Calculates estimated travel costs broken down into food, hotel, transport, and activities.
 Atlas AI Chatbot: Uses Google Gemini AI to answer travel questions and give packing suggestions.
 Admin Console: Allows managing destination lists (adding, editing, or deleting places).
 Pre-loaded Data: Comes with a database of 50+ curated Indian tourist destinations.
3. How It’s Built (Project Structure)
The project is divided into two main parts:
 Frontend (⁠/frontend⁠): Built using React Native and Expo so it can run smoothly on both Android phones and web browsers.
 Backend (⁠/backend⁠): Built using Node.js and Express to handle server requests, user logins, and data management.
 Database: Uses MongoDB Atlas in the cloud to store user accounts, saved trips, and destination details.
